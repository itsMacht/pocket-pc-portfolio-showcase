Add a subtle compact keyboard in front of the monitor if needed to make the desktop setup natural. Remove all code, terminals, scratch editors, scripts, code text, and the dominant blue wallpaper from the computer screen. No personal files, email addresses, or connection credentials. No Apple logos, extra slogans, pricing, feature badges, or watermark. Avoid an exaggerated concept UI. Crisp photorealistic editorial product photography, tasteful whitespace, soft shadows and believable screen reflections. This is a product visualization, not a literal screenshot.
